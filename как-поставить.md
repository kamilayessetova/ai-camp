# Два навыка Claude

`anti-ai-ru.zip` — считает, насколько текст похож на машинный, от 0 до 100, и помогает писать
без машинных оборотов. Нужен для батлкарт и фабрики контента.

`battlecard.zip` — собирает батлкарту конкурента по тем же правилам, что промпт П12.

## Поставить один раз

1. **Settings → Capabilities** — включить **Code execution and file creation**.
2. **Customize → Skills → Add → Upload skill** — выбрать `anti-ai-ru.zip`.
3. То же для `battlecard.zip`.

В списке Skills, в разделе «Created by you», появятся anti-ai-ru и battlecard.

## Вызвать

Написать `/anti-ai-ru` или `/battlecard` в начале сообщения либо нажать **+ → Skills** под
полем ввода. В промптах П12, Ф3 и Ф5 вызов уже вписан первой строкой. Если навык не
поставился, промпты работают и без него.
