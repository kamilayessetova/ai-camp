# Три навыка Claude

`anti-ai-ru.zip` — считает, насколько текст похож на машинный, от 0 до 100, и помогает писать
без машинных оборотов. Нужен для батлкарт и фабрики контента.

`battlecard.zip` — собирает батлкарту конкурента по тем же правилам, что промпт П12.

`ai-initiative-brief.zip` — проводит короткое интервью в чате и собирает бриф на
ИИ-инициативу: Word-документ из 12 разделов. Транскрипт не обязателен. Источник:
[ai-initiative-brief-skill](https://github.com/d-bitsak/ai-initiative-brief-skill).

## Поставить один раз

1. **Settings → Capabilities** — включить **Code execution and file creation**.
2. **Customize → Skills → Add → Upload skill** — выбрать `anti-ai-ru.zip`.
3. То же для `battlecard.zip`.
4. То же для `ai-initiative-brief.zip`.

В списке Skills, в разделе «Created by you», появятся anti-ai-ru, battlecard и
ai-initiative-brief.

Этот же навык совместим с Claude Code и Codex напрямую, без загрузки zip: папка
`навыки/ai-initiative-brief/` устанавливается копированием в `.claude/skills/ai-initiative-brief/`
(Claude Code) или `.agents/skills/ai-initiative-brief/` (Codex). Подробности — в
`навыки/ai-initiative-brief/README.md`.

## Вызвать

Написать `/anti-ai-ru`, `/battlecard` или `/ai-initiative-brief` в начале сообщения либо
нажать **+ → Skills** под полем ввода. В промптах П12, Ф3 и Ф5 вызов уже вписан первой
строкой. Если навык не поставился, промпты работают и без него.
