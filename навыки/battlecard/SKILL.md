# Батлкарта конкурента

## Когда применять

Пользователь просит собрать батлкарту, карту конкурента или разбор для продаж, и в рабочей
папке уже есть: ТЗ `00-концепт.md`, посчитанные метрики `метрики.md`, собранные записи
`data-*.json`, утверждённые углы `углы.md`.

## Проверка перед началом

Не собирать карту, если:
- в `углы.md` нет строки `approved: true` — углы не утверждены человеком;
- метрики не посчитаны кодом, а прикинуты;
- по конкуренту меньше 20 записей и это нигде не оговорено.

В любом из случаев сказать, чего не хватает, и остановиться.

## Как собирать

Структуру взять из файла `template.md` рядом с этим навыком. Карта на каждого прямого
конкурента отдельно. Заполнять по правилам:

- **Вопросы из ТЗ** — карта отвечает на каждый, сколько бы их ни было. Вопрос без данных:
  писать «данных нет» и что замерить руками. Не додумывать.
- **Цифры** — только из `метрики.md`, в том же виде. Ни одной новой.
- **Цитаты** — дословно из собранных данных, с идентификатором записи, датой и оценкой.
  Авторская пунктуация сохраняется. Свои формулировки цитатой не оформляются.
- **«Они говорят → мы отвечаем»** — аргументы конкурента дословно с его сайта и из его
  постов, со ссылкой.
- **«Где проигрываем»** — заполнять честно. Карта без честного раздела о слабостях не
  работает: продажи ей не верят.
- **Имена авторов отзывов** в карту не попадают. Вместо имени — номер записи.
- В конце раздел **«Ограничения этого разбора»**: сколько записей, за какой период, чего
  не хватило.

## Как писать

Карту читает человек перед звонком, а не проверяющий. Без вводных оборотов, без оценок
без цифры рядом, короткие и длинные предложения вперемешку. Если в проекте лежит
`11-анти-ии-русский.md` или стоит навык `anti-ai-ru` — писать по их правилам.

## Формат выдачи

Одностраничный HTML: открывается в браузере, печатается на A4, без внешних зависимостей.
Шрифт системный, таблицы с рамками, цитаты с отбивкой слева.

Сохранить файлом `батлкарта-{конкурент}.html` в рабочей папке и показать артефактом.
Файл обязателен: следующий шаг ищет его на диске.

## После сборки

Прогнать самопроверку и назвать вслух:
1. Утверждения без источника.
2. Цифры, которых нет в `метрики.md`.
3. Цитаты, которых нет дословно в данных.
4. Пустой или формальный раздел «Где проигрываем».
5. Вопросы из ТЗ, на которые карта не ответила.

Найденное исправить и показать список исправлений.
