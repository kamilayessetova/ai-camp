# Словарь лексических маркеров ИИ

Это слова, по которым русский текст опознают как машинный. Ни одно из них не запрещено
абсолютно: язык не состоит из чёрного списка. Запрещена **плотность** — когда такие слова
идут одно за другим, текст перестаёт звучать как чей-то и начинает звучать как модель.

Правило простое: увидел слово из списка — спроси, что оно добавляет. Если ничего, удали;
если добавляет — замени конкретикой из колонки справа.

## Абстрактные существительные

Их беда в том, что они называют не вещь, а категорию вещи. Читатель не может их увидеть.

| Маркер | Чем заменить |
|---|---|
| ландшафт (рынка, индустрии) | назвать сам рынок и что на нём происходит |
| парадигма | подход, способ работы — или конкретное описание |
| аспект | сторона, а лучше — что именно |
| нюанс | деталь, конкретно какая |
| контекст (в значении «фон») | обстоятельства, назвать их |
| спектр | список, перечислить |
| динамика | что выросло или упало и на сколько |
| синергия | что с чем складывается и что даёт |
| экосистема | набор сервисов, перечислить |
| вектор | направление, куда именно |
| потенциал | что можно получить, конкретно |
| реализация, имплементация | внедрение, запуск, глагол |
| обеспечение | что делаем, глаголом |
| формирование | создаём, собираем, строим |
| оптимизация | что улучшили и насколько |
| трансформация | что во что превратилось |
| эффективность | результат, цифра |
| ресурсы | деньги, люди, время — что именно |
| критерии, параметры | признаки, требования, назвать их |
| тенденции | что происходит, конкретно |
| катализатор | что ускорило и почему |
| краеугольный камень, фундамент | основа, а лучше — конкретный факт |
| инсайт | что поняли, своими словами |
| нарратив | история, версия, объяснение |
| дорожная карта | план со сроками |
| точка боли | что мешает человеку, конкретно |
| пользовательский опыт | удобство, что именно неудобно |
| вызов (в значении challenge) | проблема, задача |

## Оценочные прилагательные

Прилагательное, которое можно приписать чему угодно, не говорит ничего.

| Маркер | Чем заменить |
|---|---|
| ключевой, решающий, критический, жизненно важный | назвать, что случится без этого |
| важный (как ярлык) | показать важность фактом, а не словом |
| уникальный, беспрецедентный, революционный | чем отличается от аналогов, конкретно |
| инновационный | что нового по сравнению с тем, что было |
| комплексный, всеобъемлющий, многогранный | перечислить, из чего состоит |
| эффективный, оптимальный | цифра результата |
| современный, актуальный, на сегодняшний день | дата или «сейчас», если правда важно |
| перспективный | что даст и когда |
| динамичный, гибкий, масштабируемый | что именно меняется и как |
| значимый, существенный, фундаментальный | насколько, в чём |
| качественный, профессиональный, надёжный | по какому признаку |
| бесшовный, интуитивный, прозрачный | что происходит без лишних действий |
| клиентоориентированный, высоконагруженный | что делает для клиента, какая нагрузка в цифрах |
| релевантный | подходящий, чему именно |
| наиболее оптимальный, самый лучший | плеоназм: оставить одно слово |

## Глаголы-пустышки

| Маркер | Чем заменить |
|---|---|
| является | тире или прямое утверждение: «Х — это Y» |
| представляет собой | то же самое, без оборота |
| осуществляет, производит, выполняет | конкретный глагол действия |
| способствует | помогает, ускоряет, снижает — что именно |
| обеспечивает | даёт, гарантирует, позволяет — и что |
| подчёркивает, выделяет, отражает, демонстрирует | показывает, доказывает — или удалить |
| позволяет (в связке «позволяет сделать») | глагол напрямую |
| играет роль | назвать роль или удалить |
| направлен на | делает что-то, глаголом |
| характеризуется | какой он, прилагательным |
| интегрировать, оптимизировать, трансформировать | внедрить, ускорить, переделать |
| резонировать, коррелировать | совпадать, связаны, зависят |

## Вводные и наречия

Слова, которыми модель добирает вес там, где нет мысли.

| Маркер | Что делать |
|---|---|
| безусловно, несомненно, разумеется, очевидно | удалить: если очевидно, слово не нужно |
| поистине, действительно, по-настоящему | удалить |
| стоит отметить, следует подчеркнуть, нельзя не сказать | удалить вместе с оборотом, оставить мысль |
| важно понимать, важно помнить, необходимо учитывать | сказать мысль, не объявляя её важной |
| в свою очередь, при этом, в то же время | удалить, если не выражает реального перехода |
| по сути, в принципе, как таковой, собственно говоря | удалить всегда |
| в конечном итоге, в конечном счёте | удалить |
| в современном мире, в наши дни, в эпоху | удалить или заменить датой |
| как правило, зачастую, практически, почти всегда | сказать прямо или дать долю в процентах |
| буквально | удалить, если не буквально |

## Канцелярские предлоги и связки

| Маркер | Замена |
|---|---|
| в связи с тем, что | потому что |
| в силу того, что | из-за того, что |
| ввиду того, что | из-за |
| вследствие | из-за |
| в случае, если | если |
| при условии, что | если |
| с учётом того, что | учитывая, что |
| для того, чтобы | чтобы |
| в целях, с целью | чтобы |
| на основании того, что | потому что |
| в рамках | в, на, во время |
| в течение, на протяжении | за (месяц, год) |
| в отношении | о, про |
| посредством | через, с помощью |
| при наличии | если есть |
| данный, вышеуказанный, вышеупомянутый | этот, тот |
| имеет место быть | есть, происходит |
| в значительной степени | во многом, или цифра |

## Ритуальные обороты

Фразы-переходы и фразы-объявления, которые модель ставит по привычке.

| Маркер | Что делать |
|---|---|
| в этой статье мы рассмотрим | начать с сути |
| давайте разберёмся, давайте посмотрим, давайте погрузимся | удалить |
| перейдём к следующему аспекту | следующая мысль начинается сама |
| теперь, когда мы разобрали X, поговорим о Y | удалить связку |
| как мы уже говорили выше | удалить |
| подводя итог, в заключение, в целом, таким образом | вывод без объявления вывода |
| надеюсь, это было полезно | удалить |
| и что же делать? в чём же секрет? | максимум один такой вопрос на большой текст |
| стоит помнить, что | удалить |

## Рекламный пафос

| Маркер | Что делать |
|---|---|
| откроет новые горизонты | что конкретно станет доступно |
| выведет на новый уровень | какой результат и в каких цифрах |
| незаменимый помощник, надёжный партнёр | что делает |
| богатый, яркий, разнообразный | перечислить |
| может похвастаться | просто назвать факт |
| в самом сердце (города, отрасли) | адрес или место |
| вековое наследие, неизгладимый след | дата и факт |
| не оставит равнодушным | удалить |
| результат не заставит себя ждать | срок в днях |

## Метафоры-штампы

Модель тянется к «красивому» образу там, где нужен факт: **гобелен**, **калейдоскоп**,
**маяк**, **компас**, **мост между**, **краеугольный камень**, **золотая середина**,
**палка о двух концах**, **верхушка айсберга**, **на стыке**. Каждый такой образ — сигнал
проверить, есть ли под ним содержание. Обычно нет.

## Обтекаемые атрибуции

Самый вредный класс: выглядит как факт, но проверить нечего.

| Маркер | Что делать |
|---|---|
| эксперты отмечают, специалисты считают | имя, должность, компания |
| согласно исследованиям, исследования показывают | название, организация, год |
| статистика показывает | источник и цифра |
| многие компании, большинство пользователей | сколько именно и по чьим данным |
| принято считать, считается | кем и на каком основании |
| по некоторым данным | по чьим |

Если источника нет — утверждение либо удаляется, либо переписывается как оценка автора
с честной формулировкой: «по нашему опыту», «на десяти проектах мы видели, что…».
