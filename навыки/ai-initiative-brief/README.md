# Навык «Бриф на ИИ-инициативу»

Общий навык для **Claude Code и Codex**. Проводит короткое интервью в чате и собирает **Word-документ из 12 разделов**. Участнику достаточно идеи или описания рабочего процесса: транскрипт не нужен.

Навык задаёт до трёх вопросов за сообщение, использует уже полученные ответы и не выдумывает цифры, даты или людей. «Не знаю» и «пропустить» — допустимые ответы: пробелы останутся в документе с пометкой «Требует уточнения». Если транскрипт или заметки уже есть, их тоже можно использовать.

## Скачать

- [ZIP для Claude Code и Codex](https://github.com/d-bitsak/ai-initiative-brief-skill/raw/refs/heads/main/ai-initiative-brief.zip)
- [Файл .skill для загрузки в совместимый интерфейс Claude](https://github.com/d-bitsak/ai-initiative-brief-skill/raw/refs/heads/main/ai-initiative-brief.skill)

Оба архива содержат один и тот же навык. Для Claude Code и Codex ZIP нужно распаковать и установить **всю папку** `ai-initiative-brief`, включая `assets`, `scripts` и `requirements.txt`. Простое скачивание файла не устанавливает навык.

## Установка

Можно распаковать ZIP в указанную папку или выполнить команду Git. Выберите только один способ для каждого приложения, чтобы не создавать дубли. `~` означает домашнюю папку пользователя; в Windows это обычно `C:\Users\Имя`.

| Приложение | Папка для всех проектов | Папка только для текущего проекта |
| --- | --- | --- |
| Claude Code | `~/.claude/skills/ai-initiative-brief/` | `.claude/skills/ai-initiative-brief/` |
| Codex | `~/.agents/skills/ai-initiative-brief/` | `.agents/skills/ai-initiative-brief/` |

Внутри выбранной папки должен сразу лежать `SKILL.md`, без ещё одной вложенной папки с тем же именем. Один комплект файлов подходит обеим системам; отличаются место установки и способ вызова. Если навык не появился, перезапустите сессию.

### Claude Code

```bash
git clone https://github.com/d-bitsak/ai-initiative-brief-skill.git ~/.claude/skills/ai-initiative-brief
```

Для обновления установки через Git:

```bash
git -C ~/.claude/skills/ai-initiative-brief pull --ff-only
```

Начните в папке своего проекта:

```text
/ai-initiative-brief Помоги составить бриф на мою ИИ-инициативу. Проведи короткое интервью. У меня 30 минут.
```

### Codex

```bash
git clone https://github.com/d-bitsak/ai-initiative-brief-skill.git ~/.agents/skills/ai-initiative-brief
```

Для обновления установки через Git:

```bash
git -C ~/.agents/skills/ai-initiative-brief pull --ff-only
```

В CLI или расширении IDE можно вызвать навык так:

```text
$ai-initiative-brief Помоги составить бриф на мою ИИ-инициативу. Проведи короткое интервью. У меня 30 минут.
```

В графическом интерфейсе выберите навык в доступном списке или попросите использовать `ai-initiative-brief` обычным сообщением.

### Без команд установки

Распакуйте ZIP в рабочую папку и попросите агента:

> Установи навык из папки ai-initiative-brief для текущего приложения. Скопируй весь комплект в подходящую папку навыков. Затем используй его, чтобы провести со мной интервью и собрать бриф.

Агент может запросить разрешение на запись в папку навыков или установку Python-зависимостей.

Для интерфейса Claude с функцией импорта навыков используйте `.skill`. Терминальные Claude Code и Codex устанавливаются через папку навыка, как описано выше.

## Как проходит практика

1. Откройте рабочую папку в Claude Code или Codex и вызовите навык.
2. Назовите инициативу или процесс, который хотите улучшить. Если идеи пока нет, агент поможет выбрать одну задачу.
3. Отвечайте на короткие блоки вопросов: текущий процесс и проблемы, идея и польза, пользователи, метрики, данные, ограничения, сроки и команда.
4. Если не знаете ответа, так и напишите. Чтобы закончить раньше, скажите: «Собери бриф сейчас, неизвестное отметь как требующее уточнения».
5. Получите `.docx` и исходник `.md` в рабочей папке. При отсутствии возможности собрать Word агент сохранит Markdown и объяснит, чего не хватает.

Пример стартового запроса:

> Хочу сократить время подготовки коммерческих предложений. Проведи со мной интервью и собери бриф на ИИ-инициативу. Транскрипта нет. Не придумывай цифры и сроки.

Для готового интервью:

> Используй ai-initiative-brief: собери бриф по файлу интервью.docx, а недостающие сведения уточни у меня в чате.

## Python и Word

Для сборки Word нужен **Python 3.9+** с `python-docx`. Git нужен только для установки клонированием; для ZIP он не требуется. Агент может использовать уже доступный Python с нужной библиотекой. Если библиотеки нет, создайте виртуальное окружение в рабочей папке. Активация окружения не требуется.

macOS / Linux, из рабочей папки:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r "/полный/путь/к/ai-initiative-brief/requirements.txt"
.venv/bin/python "/полный/путь/к/ai-initiative-brief/scripts/build_brief.py" "/полный/путь/к/brief_filled.md" "/полный/путь/к/Бриф.docx"
```

Windows PowerShell, из рабочей папки:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r "C:\полный\путь\к\ai-initiative-brief\requirements.txt"
.\.venv\Scripts\python.exe "C:\полный\путь\к\ai-initiative-brief\scripts\build_brief.py" "C:\полный\путь\к\brief_filled.md" "C:\полный\путь\к\Бриф.docx"
```

Замените примеры путей на реальные. Если команда `py` недоступна, используйте доступный Python 3 (`python`). Глобальная установка пакетов не требуется.

Для чтения текстового PDF дополнительно установите `pypdf` тем же интерпретатором: `<python-из-venv> -m pip install pypdf`. Также поддерживается уже установленный `pdfplumber`. Для сканов нужно отдельное OCR-средство или текстовая версия; можно вместо этого пройти интервью в чате.

## Структура брифа

Звёздочкой отмечены обязательные разделы. Заголовки, порядок и курсивные подсказки сохраняются даже при пропуске ответов.

1. Название инициативы*
2. Контекст*
3. Ваша идея*
4. Проблемы бизнеса*
5. Бизнес-цели*
6. Job Story (опционально)
7. Критерии успеха
8. Измеримые цели
9. Ограничения и доп. требования
10. Источники данных и знаний
11. Сроки — начало, MVP, масштабирование
12. Проектная группа — владелец портфеля, заказчик, аналитик, разработчик, другие участники

## Файлы и примеры

- `SKILL.md` — интервью, правила работы с фактами, сборка и выдача результата.
- `assets/template.md` — канонический шаблон; `assets/example_filled.md` — только образец оформления.
- `scripts/read_transcript.py` — чтение необязательного транскрипта из TXT, MD, DOCX или текстового PDF.
- `scripts/build_brief.py` — сборка Word из заполненного Markdown.
- `requirements.txt` — зависимость для Word.
- [examples/kp-assistant/](https://github.com/d-bitsak/ai-initiative-brief-skill/tree/main/examples/kp-assistant) — синтетический пример работы с транскриптом, а не факты для новых брифов.

После изменения исходников пересоберите оба архива командой `python3 scripts/package_skill.py`. Упаковщик включает только файлы навыка и инструкцию установки, без Git, окружений и результатов пользователей.

Формат и установка: [Claude Code Skills](https://code.claude.com/docs/en/skills), [Codex Skills](https://developers.openai.com/codex/skills/).
